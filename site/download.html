Install Mnemosyn

Mnemosyn installs from source with Python. Pick your system, then run each step in a terminal. The whole thing takes a few minutes, most of it downloading.

System
What to install

  1. Check Python and Git

    You need Python 3.11 or newer and Git. Both commands should print a version number.

    python3 --version
git --version
    py --version
git --version

    Missing one? Install Python from python.org or with Homebrew (brew install python git).

    Missing one? Install Python from python.org and Git from git-scm.com. Use PowerShell for every step.

    Missing one? Use your package manager, for example sudo apt install python3 python3-venv git or sudo dnf install python3 git.

  2. Get the code

    Downloads the project into a folder called mnemosyn and moves into it.

    git clone https://github.com/saeeedhany/mnemosyn.git
cd mnemosyn

  3. Create a private Python environment

    Keeps Mnemosyn's libraries in .venv inside the folder, away from the rest of your system.

    python3 -m venv .venv
    py -m venv .venv

  4. Install

    Installs the desktop app (Qt, VTK) and the atlas build tool. This is the longest download.

    Installs the terminal viewer and the atlas build tool, without Qt.

    .venv/bin/pip install -e ".[desktop,atlas-build]"
    .venv\Scripts\pip install -e ".[desktop,atlas-build]"
    .venv/bin/pip install -e ".[atlas-build]"
    .venv\Scripts\pip install -e ".[atlas-build]"

  5. Build the atlas

    Downloads each dataset from its original publisher, checks every file against a pinned checksum, then builds the atlas into atlases/cns. Processing takes about 15 seconds. Downloads are cached, so running it again is quick.

    .venv/bin/python -m tools.build_atlas
    .venv\Scripts\python -m tools.build_atlas

    Optional for the terminal viewer: without an atlas it shows the simplified 36-region brain.

  6. Launch

    Opens the desktop app. Press F1 inside it for the data sources and licences.

    .venv/bin/mnemosyn
    .venv\Scripts\mnemosyn

    On a hybrid-GPU laptop, start it with prime-run .venv/bin/mnemosyn to use the discrete GPU.

    Opens the viewer in your terminal. Press ? for the keys.

    .venv/bin/brain-tui
    .venv\Scripts\brain-tui

Update

From inside the mnemosyn folder: get the latest code, reinstall, and rebuild the atlas in case its sources changed.

git pull
.venv/bin/pip install -e ".[desktop,atlas-build]"
.venv/bin/python -m tools.build_atlas
git pull
.venv\Scripts\pip install -e ".[desktop,atlas-build]"
.venv\Scripts\python -m tools.build_atlas
git pull
.venv/bin/pip install -e ".[atlas-build]"
.venv/bin/python -m tools.build_atlas
git pull
.venv\Scripts\pip install -e ".[atlas-build]"
.venv\Scripts\python -m tools.build_atlas

Uninstall

Everything lives in three places. Delete the mnemosyn folder, then, if you want them gone too, the download cache in ~/.cache/cns-atlas and your quiz progress in ~/.local/share/mnemosyn.

If something goes wrong

The install says my Python is too old

Mnemosyn needs Python 3.11 or newer. Install a newer Python, delete the .venv folder and repeat from step 3.

The atlas build stops during a download

Run the build command again. Files that already downloaded are cached and checked, so it continues where it stopped. A checksum error means the file changed on the publisher's side; please open an issue.

The app opens but the brain is missing

The atlas hasn't been built in this folder. Run step 5 from inside the mnemosyn folder; it writes atlases/cns, which the app and the terminal viewer look for.

It's slow on my laptop

On Linux laptops with two GPUs, start it with prime-run. The 3D view also switches to a lighter level of detail on its own when a scene gets very large.

Something else

Open an issue with your system, Python version and the full error message.
