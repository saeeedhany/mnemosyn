Overview

One atlas, four ways to study it

The name joins Mnemosyne, the Greek goddess of memory, with the synapse, where memories are stored. Each view reads the same atlas package, so what you learn in one carries over to the others.

Desktop app

Turn the brain in your hands

Every structure is drawn in one scene and picked on the GPU, so it stays at your display's refresh rate even on an integrated GPU. Hide, isolate and filter structures by name, abbreviation or synonym. Click one to read its description and references.

  • HHide the selection
  • IIsolate the selection
  • TShow or hide all 43 tracts
  • CCentre the slice on the selection
  • CtrlFFilter the structure tree
  • F1Data sources and licences
Slices

Cut through any plane

Axial, coronal and sagittal sections with coloured labels over the Colin27 MRI template, in neurological convention. Move the plane, hover a label, click to select. Try it below on the simplified brain.

Study

Quizzes that schedule themselves

Reviews are spaced with FSRS, the method Anki uses, with at most 20 new items a day per mode. Typed answers accept synonyms, abbreviations, any word order and small typos. Progress is saved after every answer.

  • Name itA structure lights up on both sides. Type its name or pick one of four.
  • Find itYou get a name. Click the structure in 3D or in a slice.
  • FlashcardsReviewed descriptions only, so you never drill a draft.
  • TractsA level of its own, with the grey matter around each tract dimmed.
Terminal viewer

The whole atlas over SSH

brain-tui reads the same atlas package and renders it in the terminal at about 30 frames per second. Rotate, slice, explode, bookmark views and quiz yourself. Without an atlas it falls back to the simplified brain shown above.

$ brain-tui --atlas atlases/cns

  arrows / hjkl   rotate        1 2 3   axial · coronal · sagittal
  + / -           zoom          , .     move the plane
  /               search        x       explode
  i  Shift+H  u   isolate       b       save a bookmark
  z               quiz          ?       help
How the atlas is built

Nothing in it is unsourced

The atlas isn't shipped as a finished download. You build it on your machine from the original publishers' files, with every check below run on each build.

1 · Fetch

Original sources

Each dataset is downloaded from its publisher and checked against a pinned SHA-256 checksum.

2 · Licence

Redistribution

A source without a licence that allows redistribution is refused.

3 · Identity

Stable ids

Structure ids never change and are never reused. A lock file records every published id.

4 · Knowledge

Cited text

Every description cites references with a DOI, URL or ISBN, and stays a draft until reviewed.

5 · Package

Meshes and volumes

Meshes at three levels of detail and a labelled volume, written to atlases/cns.

FAQ

Questions

Something missing? Open an issue.

Is Mnemosyn free?

Yes. The code is licensed under the GNU GPL v3.0 or later. Each dataset keeps its own licence (GPL, CC BY 4.0, CC BY-SA 4.0 and a permissive notice), and the descriptions are CC BY 4.0.

Can I use it for clinical work?

No. Mnemosyn is a study tool. It has not been reviewed by a specialist yet and may contain errors. Do not use it for diagnosis or treatment.

Who checks the anatomy?

Specialists in neuroanatomy and related fields, using a review packet and a short form. Descriptions stay marked Draft until a reviewer has checked them, and quizzes only show reviewed descriptions as flashcards. See how to review.

Which systems does it run on?

It's a Python 3.11+ app built on Qt and VTK, which run on Linux, macOS and Windows. It's developed and tested on Linux; macOS and Windows haven't been tested yet, so please report anything that breaks.

Do I need a powerful GPU?

No. With all 166 structures it reaches the display's refresh rate (144 Hz) on an integrated GPU. On hybrid-GPU Linux laptops, prime-run moves it to the discrete GPU.

Why do I build the atlas myself?

Building fetches each dataset from its original publisher, checks it against a pinned checksum and packages it with its licence and citation. It takes one command and about 15 seconds of processing after the downloads.

Where is my quiz progress stored?

Only on your computer, in ~/.local/share/mnemosyn/progress.sqlite. Nothing is sent anywhere.

How can I help?

If you're a specialist, review a part of the atlas. Otherwise you can fix bugs, write or translate descriptions, or test on macOS and Windows. Every kind of help is credited on the contributors page.
